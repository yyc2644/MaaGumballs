# Maze Entrance Assets

统一存放迷宫大地图入口模板和待识别候选图。

- 共 30 张，均为 71×61、32-bit ARGB PNG。
- 文件按索引图中的编号命名。
- `MazeEntrance_Candidate_17.png` 是已点击验证的沉眠小镇入口候选原图。
- `Sleeptown_Entry.png` 是沉眠小镇当前正式使用的入口模板。
- `MazeEntrance_Candidates_Index.png` 用于快速查看和人工辨认全部候选。
- 固定顶部状态栏后方有一个无法完整露出的入口，因此未生成不完整模板。

这些图片保留原始截图像素，没有经过生成、缩放、锐化或颜色调整。
