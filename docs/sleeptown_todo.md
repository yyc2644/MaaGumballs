# 沉眠小镇未完成事项

本清单只覆盖当前目标范围：普通层到 51 层、Boss 到 50 层。完成一项后，
应同步补充自动化测试和一次真机/模拟器验证记录。

## P0：阻塞完整流程

- [ ] `ST-01` 完成 50 层 Boss 策略：确定濒死阈值、Boss 单次伤害、祝福术
  使用方式、可用道具及优先级、耗尽兜底和胜利判定。
- [ ] `ST-02` 确定目标层语义：目标为“打完 50 层 Boss”时，是否必须继续
  清完 51 层并使用“退退退”；同步修改 GUI 默认目标和结算触发点。
- [ ] `ST-03` 真机验证 51 层“退退退”：确认堆叠物品的“使用一次”按钮、
  使用后的动画/确认框、实际返回层数和最长生效时间。
- [ ] `ST-04` 确定大地之门策略：在哪一次到达 49 层使用、最多几次、没有
  魔法时是否继续，以及与“退退退”的优先关系。

## 神锻系列测序模板

模板入口：`Sleeptown_DivineForge_Sequence_Template`。默认 `enabled=false`，
不会点击、熔炼、消耗物品或小 SL。

- [ ] `SDF-01` 明确候选对象名称、星级/数量和背包位置。
- [ ] `SDF-02` 明确测序前基线：攻击、物品数量、属性或界面图标。
- [ ] `SDF-03` 明确每次推进序列的神锻动作及资源消耗。
- [ ] `SDF-04` 明确成功判据：模板、OCR、属性差值或特效。
- [ ] `SDF-05` 明确每轮恢复方案及安全条件，特别是是否允许小 SL。
- [ ] `SDF-06` 明确序列长度、候选优先级、结果保存格式和停止条件。

模板主循环应按以下顺序实现：准备候选 → 记录基线 → 执行一次探测 → 判断
结果 → 记录序列 → 恢复现场。仓库原有 `divineForgeLand/someTrick.py` 可作为
熔炉101序列参考，但它会实际熔炼装备并执行小 SL，不能在规则未确认时直接复用。
