# 卡牌幻境实现状态

Card 主流程已改为 OCR + 通用战斗状态机，不再把缺失的专属图片当作必需条件。

## 已落地

- 大地图入口使用“卡牌幻境”OCR，局内也可直接接管。
- 小怪层：冥想、四象封印、通用全清。
- Boss层：连斩两次、冥想、进入龙心、抽魂、瓦解、四象、斩杀及通用清层兜底。
- 公共事件：安全选项优先级、亚瑟王圆桌、神龙愿望、卷轴商店。
- 长线能力：封印之书检查、称号路线、HP恢复、神圣重生、死亡小SL。
- 下楼复用 Mars/JJC 的门缓存和神秘洞穴保存等待流程。
- 结算只在目标层完成清理且门已打开后触发，不会提前两层离开。
- 连续同层重试超过阈值时截图并暂离保存恢复。

## 后续可选模板（不是运行前置条件）

实机日志若证明某个 OCR 节点不稳定，再针对该节点补小范围模板即可：

- 卡牌面板入口和单张技能卡（冥想、连斩）。
- 龙之心入口与心脏目标。
- 斯巴达尸体、法师、蛮牛、树妖等格子事件图标。
- 装备商店与卷轴商店的关闭/确认按钮。

模板只应作为 OCR 失败后的局部兜底，不应恢复旧实现中“模板缺失就固定返回未命中”的行为。

## 实机验证建议

先选择 95 层做一轮冒烟测试，重点观察：

1. 1–3 层卡牌面板与冥想 OCR。
2. 30 层首个 Boss 的龙心入口坐标。
3. 39、63、69 层称号路线。
4. 第一次神龙愿望文本和返回主界面的行为。
5. 神秘洞穴出现时，保存状态后等待人工验证是否能继续。

确认上述节点后再将目标切到 1201。
